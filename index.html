Constraints are validation

The IMO check digit, MMSI shape and allowed alert kinds are CHECK constraints. Bad data never gets in.

Triggers are the detectors

Every INSERT INTO ping runs gap, spoof, rendezvous and loitering checks in the same transaction.

Views are the analytics

Risk, darkness and exposure are views, so they are always current and every component is explainable.

Graphs fit in SQL

A recursive CTE walks shell-company chains, multiplies stakes along each path and stops at cycles.

The scenario is data

Scripted events are rows in scenario. The tick applies them with UPDATE … FROM.

Evidence is immutable

A trigger aborts any attempt to edit a position report. Alert triage is written to an audit log by trigger.
